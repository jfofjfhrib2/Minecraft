BLOCKWORLD

Eine eigene 3D-Blockwelt im Browser. Baue, grabe und erkunde dein Terrain.

Desktop: WASD, Maus, Linksklick, Rechtsklick
Inventar: E   |   Pause: Esc
Smartphone: Touch-Schaltflächen verwenden
Leben: 20
Position: 0 / 0 / 0
Zeit: Tag
WASD = Bewegen
Leertaste = Springen
Linksklick = Block abbauen
Rechtsklick = Block platzieren
E = Inventar
F = Speichern
Esc = Pause

Inventar

Wähle einen Block für deine Hotbar aus.

Pausiert

Das Spiel ist angehalten.
